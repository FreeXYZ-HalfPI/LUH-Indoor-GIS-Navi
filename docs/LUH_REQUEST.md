**Subject:** Open-source indoor navigation for LUH: request for data permission and contact

Dear Sir or Madam,

I am building a free, open-source (GPL-3.0) indoor navigation web app for
Leibniz Universität Hannover. It guides students and visitors from one room
to another, including the way between buildings. It works in the phone
browser without installation, GPS, accounts or tracking, and routes are
computed on the device.

The prototype covers 5 buildings (1101, 3101, 3109, 3110, 3408):
https://freexyz-halfpi.github.io/LUH-Indoor-GIS-Navi/
Source code and documentation: https://github.com/FreeXYZ-HalfPI/LUH-Indoor-GIS-Navi

So far it uses public data: room lists and floor-plan images of Rauminfo
(CAFM), building data of the Standortfinder, and OpenStreetMap. The floor
plans are linked, not copied. I would like to do this properly and ask for:

1. **Permission** to use the public Rauminfo / Standortfinder data and the
   graphs derived from the floor plans in this project.
2. If possible, an **official export** (floor plans as CAD/DWG/IFC, room lists,
   entrances, lift and barrier-free information) for more buildings.
3. A **contact person** for questions, corrections and data updates.
4. Your view on the **people search** (names, roles and office rooms from
   public LUH pages, without phone or e-mail), including an opt-out process.

I would be glad to present the project or to run a field test with students.

Kind regards,
